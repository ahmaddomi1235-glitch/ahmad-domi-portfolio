# sources/ — private inputs (git-ignored)

Nothing in this folder is committed (see `.gitignore`). It holds the raw material the knowledge base is built from.

- `official/`    Pearson / Ministry documents. Copyrighted — never commit, never republish wholesale.
- `ahmad/`       Ahmad Domi's own files. Paid or private material lives here and must never become a public route.
- `transcripts/` Raw YouTube captions (`raw/*.vtt`, `*.info.json`) and cleaned text. Used to *verify* and *draft*;
                 never published as-is.

Imported material defaults to `status: draft`, `visibility: PAID` until a human publishes it deliberately.
